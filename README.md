# Carivsue · Estudio Creativo

Web inicial responsive para Carivsue, creada con HTML, CSS y JavaScript sin dependencias de compilación.

## Cómo verla
Abre `index.html` en tu navegador.

## Cómo publicarla con GitHub Pages
1. Crea un repositorio en GitHub, por ejemplo `carivsue-web`.
2. Sube `index.html`, `logo-carivsue.jpg` y `README.md` a la raíz del repositorio.
3. En GitHub, entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y `/ (root)`, y guarda.
5. Espera a que GitHub Pages publique la web y te muestre la dirección.

## Personalización y notas
- Se conserva el archivo del logo original sin editar y se utiliza como imagen de marca.
- La paleta se inspira en el logo: marfil, gris cálido y lila suave.
- WhatsApp e Instagram enlazan a los datos incluidos en el encargo.
- Esta es una web escaparate con contacto por WhatsApp; todavía no tiene catálogo con inventario, pagos, cuentas de cliente ni gestión de pedidos.
- Antes de publicar, revisa los datos de contacto, añade fotos reales de productos y prepara textos legales (aviso legal, privacidad, cookies y condiciones de venta) según corresponda.
